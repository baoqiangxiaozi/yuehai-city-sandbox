## 2026-11-25 按实机截图改的三项

用户用桌面 Chrome 打开了当时的单页（`file:///C:/Users/29750/Desktop/yuehai-v4-index.html`），时间 09:04，灯光为自动。截图里腾讯滨海双塔是一整面近黑的实墙，采样约 `#1a221f`，和场景半球光地面色 `0x1a2418` 一致，不是浅玻璃 `#c5d0cc` 的本色。连廊材质是近黑 `#3e3832`，竖梃是 `#4a5552`。旧的地标玻璃外壳没有套在这座楼上，因为生成建筑时已经跳过它。

这一轮只改三件事：

1. 取消腾讯滨海的黑墙。塔身改为浅色不透明玻璃 `glass_tower`（`#d7e4de`，自发光 `#e7f0ec` / 1.05），竖梃和横档改为浅灰 `metal_tower`（`#d2dbd6`），连廊主体改为中灰 `#6a7872`。环境反射强度降到 0.12，避免城市贴图把浅墙再拉黑。双塔、三连廊、高度和位置没改。玻璃仍是双面不透明，没有回到能透视内部的线框。
2. 其余标名建筑的玻璃改为深青灰 `#24343c`，次级玻璃 `#1c2c34`。金属、石材、铜、屋顶和白色壳体没有跟着染黑。华润只改了玻璃颜色，网格仍是 36036 三角面。夜窗保留，白天关闭。
3. 取消漫游。进入按钮、HUD、触控方向键、WASD 说明和控制器都已删除。保留自由观察、自动环绕、跟随地标、拾取、图层和天气。

下面几节里关于浅色腾讯幕墙、深色连廊和漫游实测的句子，记录的是改这三项之前的状态。当前页面以本节为准。

## 和仓库、v4 包的关系

仓库原来的单页和 v4 源码包使用同一份 OSM JSON（SHA256 `8b621052a50f7ce7c66328f8d9532a5dd521296f8416d199ddbdf6a80f8e670d`）。v4 在此之上增加了内联的 Three.js r128、漫游、普通楼 LOD、启动失败的中文提示，以及腾讯滨海、华润两座 Blender 模型。这些都保留了。

仓库原有的 GitHub Pages 工作流和 `.nojekyll` 也保留。本分支不推 `main`，因此不会触发 Pages。

Three.js 仍是 r128，SHA256 `9274bbcec8d96168626c732b5d31c775aa8cfb7eaa0599bec0c175908a2c1ce2`。没有升级 Three，没有新增运行时依赖，没有高斯泼溅，没有在线更新 OSM。

## 腾讯滨海大厦改了什么

上一版（锯齿幕墙、铜门架、大裙楼、暴露桁架，约 28748 三角面）已从页面移除，新模型不会和它叠在一起。

新模型 5326 三角面：

- 南塔、北塔使用 OSM 轮廓和高度 245.8 米 / 194.8 米，朝向烘焙在顶点里。没有改成百科上的 248 米。
- 幕墙是浅色玻璃上的横档和竖梃。横档约 0.9 米高、竖梃约 0.62 米宽，间距比真实幕墙更疏，否则整栋入画时格子会小于一个像素。这是沙盘放大，不是实测模数。
- 三条水平连廊：低连廊 22–58 米（按街景，近似），中连廊为南塔 21–25 层，高连廊为南塔 35–38 层。连廊是深色体，带约 2.2 米的铜色边框和玻璃侧板。边框加粗同样是为了能看清，不是实测杆件。
- 平屋顶。没有大裙楼，没有桁架。

## 页面行为

- 旧的专用 JS 构建体已停用，包括会把口岸、保利、海岸城再画一遍的修复函数。通用楼会跳过这些地标的 OSM 索引，所以底下没有第二套棱柱。
- 拾取、地标卡、夜景、环境反射和建筑图层仍然接到这些模型。建筑图层关闭时，模型的父组不可见。
- 普通楼 LOD 仍是 160 米分块、250 毫秒节流、近景 180/240 米、中景 600/720 米。测试里通用楼计为 2221 栋、491 块。这比早期口头说的 2212 多，因为口岸附近若干未命名低楼没有被划进口岸模型，仍作为通用楼保留。
- 第一人称漫游已从页面移除。镜头是俯瞰轨道相机。
- 车流等数字仍标为模拟。

## 浏览器里量过的操作

下面四条是取消漫游之前的无头 Chrome 记录，当前页面已经没有这些入口，不能再按它们验收：

- Shift：真实按下 KeyW，再按下 ShiftLeft。不用墙钟。按键按住后用固定 `dt = 0.05` 调用 `roam.update` 各 20 次。位移 0.696 和 2.784，比值 4.00。无头浏览器的帧间隔不稳，所以不把墙钟上的按住时长说成 4 倍。
- R：真实 KeyR。相机回到进入时的 `(84.5553, 0.3404, -26.477)`。
- 失焦：真实按住 KeyW 后派发 `window` 的 blur。随后两次 `update(0.05)` 位移是 0。
- 窄屏触控垫：页面直接以 390×844 打开。先点开面板，再点「进入第一人称」。触控垫为显示状态，约 162×114。对前进键做真实 pointerdown，再用固定 dt 更新 12 次，位移 0.418，与不按 Shift 的步长一致。用 `isMobile` 去改一个已经在漫游中的桌面视口时，页面不再处于漫游，那一次不算通过。截图 `final/roam-pad.png`。
- LOD：把观察点设到 `(-92.2, 8, -68.5)` 后近景块 9、中景块 42、远景块 440。设到 `(0, 40, 4000)` 后近景 0、中景 0、远景 491。这是程序移动观察点，不是鼠标拖近。

- 软件基地三栋、彩讯、创新中心附楼、深创投大厦的竖梃位置已按修正重生成，这一轮没有重新打开近景。
