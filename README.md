# 粤海：山海之间的科技城 · 3D 城市沙盘

本包是**粤海街道单文件版**城市沙盘。用 OpenStreetMap 建筑轮廓和路网（ODbL）在浏览器里生成可交互的三维场景，包含昼夜、天气、交通模拟、地标精模和世界控制面板。

这不是精确地图。建筑轮廓来自 OSM 快照，车流、拥堵、风速和天气都是**模拟演示**，不是实时路况或真实气象。

## 这个包里有什么

- `index.html` — 构建好的单文件页面，CSS、JS、OSM 数据、两座地标几何和 Three.js r128 全部内嵌，可脱机打开。
- `src/yuehai.shell.html`、`src/yuehai.css`、`src/yuehai.js` — 页面外壳、样式和场景源码。
- `src/yuehai.roam.js` — 独立第一人称自由漫游控制器，构建时同样内联。
- `src/yuehai.lod.js` — 普通楼附加细节的静态分块与距离 LOD，构建时内联。
- `src/yuehai.refined.js` — 两座 Blender 地标的材质、环境反射和夜景接入策略。
- `landmarks/` — 两座已完成地标的内联数据、适配器、可编辑 `.blend`、GLB 和来源说明。
- `tests/roam.test.js` — Node 纯逻辑 / 模拟 DOM 相机集成测试，不是浏览器验收。
- `tests/lod.test.js`、`tests/generic-fixture.js` — Three.js 几何与 LOD 测试；不运行浏览器/WebGL。
- `tests/landmarks.test.js` — 两座实际资产、接入位置、夜景、反射、射线与原图层挂载测试。
- `data/yuehai-osm.json` — 已投影的粤海 OSM 建筑 / 路网 / 地铁 / 水域数据（2026-10-28）。
- `vendor/three.min.js` — 与页面配套的 Three.js **r128**（不要换成其他版本）。来源与校验见 `vendor/README.md`。
- `scripts/build_page.py` — 把上面的源文件和 vendor 重新合成 `index.html`。
- `README-yuehai.md` — 本版实现细节和开发过程记录。其中的帧率数字是当时机器上的历史记录，不是现在的实测成绩；文中提到的部分旧路径（如前海页面、数据构建脚本、验收截图）也不在本包内。
- `GROKBOT.md` — 源码修改与构建备注。
- `.nojekyll` — 若放到 GitHub Pages，避免 Jekyll 处理隐藏文件。

本包**没有**前海升级版（`qianhai.html`、`src/qianhai.js`、`styles/qianhai.css`、`scripts/build_qianhai_data.py`、`README-qianhai.md`），也**没有**从 GeoJSON 重新生成数据的 `scripts/build_yuehai_data.py`。当前数据就是 `data/yuehai-osm.json`。

## 打开页面

直接用浏览器打开根目录的 `index.html` 即可，**不必访问 CDN，也可以脱机使用**。

或者在项目根目录启动本地服务：

```bash
python -m http.server 8000
```

然后访问 <http://127.0.0.1:8000/>。

如果 Three.js 未能载入或启动超时，页面会停留在启动屏并给出中文错误说明，而不会一直停在「正在启动城市沙盘…」。

## 修改后重新构建

不要直接改构建出来的 `index.html`。改 `src/`、`data/yuehai-osm.json` 或 `vendor/three.min.js` 之后，在项目根目录运行：

```bash
python scripts/build_page.py
```

需要 Python 3，构建脚本只用标准库。构建会覆盖根目录的 `index.html`，并把 `vendor/three.min.js` 内联进去。

## 第一人称 · 自由漫游（v3 / T-2）

**入口**：右侧「世界控制」面板 →「镜头」→ **进入第一人称 · 自由漫游**。
窄屏默认收起面板，先点屏幕右侧 `WORLD` 展开，再在面板内向下滚到「镜头」。
原有「自由观察 / 自动环绕 / 跟随地标」仍是俯瞰轨道控制，保留不变。

进入后会隐藏原面板，显示始终可用的漫游控制条：

- **W / ↑** 前进，**S / ↓** 后退，**A / ←** 左移，**D / →** 右移；移动始终在水平面内。
- **鼠标左键按住画面拖动**转向（触屏同样拖动画面），向右拖向右看，向上拖向上看。
- **Shift** 按住加速；**R** 或「复位到起点」回到本次进入时验证的道路起点。
- **Esc** 或「退出漫游」恢复进入前的俯瞰位置和镜头模式。
- **返回总览**直接回到默认俯瞰镜头，停止自动环绕，恢复「自由观察」。
- 窄屏 / 粗指针设备左下角有「前 / 左 / 后 / 右」按住移动按钮，另一手可拖动画面转向。
- 松开方向键、触控取消、窗口失焦、切到其他标签页、退出或复位都会清空移动输入。
  失焦后请松开再按移动键。

不使用 Pointer Lock、不申请权限，也不需要 HTTPS，因此脱机 `file://` 和本地 HTTP 均可使用拖动转向；
鼠标拖动边缘不够时，松开后再拖一次。漫游期间原相机拖拽、滚轮缩放、自动环绕和地标点击不会争抢视角。

**起点与尺度**：优先在科苑南路附近选一段道路的中点，按距 `(1460, -450)` 米的远近尝试；
进入前对当前实际建筑几何做垂直射线及约 3 米四向缓冲检查，避开建筑/裙房。
若找不到起点会提示而不切换模式。起点实际视角仍需浏览器核对，不能只凭逻辑测试保证画面。
固定道路高度上方 1.7 米视高（按现有 `HS` 换算），水平移动按 `PLAN` 换算；
普通速度约 12 米/秒，加速 4 倍，属于便于游览 5 公里场景的自由漫游速度，不是步行测量。
X 边界为 ±2500 米，Z 边界为 -2500 到 2300 米。

**明确限制**：第一版是自由漫游，只有固定视高和地图矩形边界，**没有建筑碰撞、地形跟随、楼梯/桥面高度、重力或水面阻挡**。
行进时可以穿过建筑、车流和水面；可用 R 复位或返回总览脱离遮挡。车流、天气和风仍为模拟，不新增真实数据接口。
漫游的实际渲染性能、完整城市起点外观和触屏手感须用浏览器验收，不用历史 FPS 代替。

## 普通楼程序化细节与分层 LOD（v4 / T-3）

**这不是实测建筑建模。** 普通楼的窗框、入口、雨棚、基座、屋顶设备均为程序化示意，
不代表真实门址、用途、材料或楼顶设施。本轮不修改 OSM 文件、不改普通楼基础轮廓/高度/位置，
普通楼 LOD 不触碰重点地标，不动原建筑拾取 face 索引；本包另外整合两座 Blender 精修地标，见下节。近景细节是已有体量上的装饰附加层。

### 真正新增 / 复用的内容

- 在普通楼最长的两个合适外立面加基座线；选一面加深色门厅、门框、薄雨棚和小台阶。
- 每栋最多给 **4 个现有窗灯面板位置**加几何细框；不再铺一套重叠窗片、不增加新窗灯。
  原幕墙 shader 的窗格、昼夜反射、窗灯占用率和种子继续复用。
- 原来已有的普通楼屋顶设备三角形从全城屋顶合批里**迁移**到中景分块，不画双份。
- 原来没有设备且内部能放得下的屋顶，近景增加一台小型设备和三条格栅；已有设备不再叠放新机箱。
- 重点地标及其登记建筑排除在普通楼装饰之外。夜景开关仍控制原灯光系统；新增物体是非自发光实体，
  随正常场景照明变化，不另开夜间常亮通道。建筑图层关闭时所有普通楼附加物随之隐藏。

### LOD 距离与开销边界

按 **160 米网格**静态合批，所有几何只在初始化时生成；每 **250ms** 检查一次相机距离，
只切换缓存 mesh 的可见性，不在移动时重建网格。

距离采用相机到分块三维建筑包围盒的最短距离，除以现有 `PLAN` 换算；不是相机到单栋楼中心的距离。
当前仍保留项目原有竖向夸张，因此它是场景距离换算，不是精密地理测距。

| 状态 | 接近时 | 远离时（滞回） | 实际提交的附加几何 |
|---|---|---|---|
| 近景 | ≤180 米进入 | >240 米退出 | 基座/门厅/框/雨棚/新增屋顶设备 + 原屋顶设备 |
| 中景 | ≤600 米进入 | >720 米退出 | 仅复用原屋顶设备（本来没有设备的分块不会凭空增加 mesh） |
| 远景 | 在中景阈值外 | 同左 | 不提交上述附加细节；继续保留原基础体量、原幕墙和夜间窗灯 |

这是真正的几何可见性 LOD，而非调亮度冒充细节切换。近景到中景、到远景都有不同的实体几何。
已有幕墙和夜景保留是为了不破坏原画面：**本轮不声称整座城市的全部几何都已做 LOD**。
不盲目拆原基础大 mesh，不改旧拾取映射。附加块开启视锥剔除，但原基础网格的策略保持不变。
每块最多一个近景合批和一个复用屋顶合批，共享材质，不是每栋/每窗一个 draw call。

所有层级缓存仍占内存；远景只是**不提交额外细节绘制**，不代表释放远处分块的 GPU/CPU 内存。
`ordinaryLOD.stats()` 里的 active mesh/triangle 是**附加层的逻辑上界**，不含基础城市场景、
阴影重复 pass，也未扣去视锥剔除，不是实际 GPU draw call 或 FPS。

### 浏览器里怎么看到切换

1. 默认总览下附加细节为远景关闭。进入「第一人称 · 自由漫游」，靠近普通楼观察基座、门厅雨棚、已有亮窗面板的浅色细框。
2. 沿道路靠近/远离同一片普通楼。近景约 180 米进入，退到 240 米外退出；继续远离到 720 米外连中景屋顶设备也不绘制。
   切换粒度是整个分块，不是每栋独立渐变；边界附近有滞回，不会因来回一两米高频闪烁。
3. 「返回总览」后这些附加物消失，原城市基础体量和窗灯仍在。
4. 控制台只读检查：`__YUEHAI__.ordinaryLOD.stats()`；也可用 `debugChunks()` 查看块的 level(0远/1中/2近)、距离和对应建筑索引。
5. 更明确的调试对比：漫游下挑一栋普通楼，暂停观察，再在控制台分别隐藏/显示名字以 `ordinary-near-` 开头的 mesh，可辨认具体附加几何；
   正常自动 LOD 在下一次更新会恢复可见性，最终验收仍应以实际距离移动切换为准。
6. 验证建筑图层关闭不遗留门厅/设备；切到夜间并关闭夜景时没有新加常亮窗片；
   普通楼仍可点中原卡片，地标聚焦、原俯瞰控制及漫游退出仍工作。

这些仅是几何预算与状态检查，不能称为实际 GPU 量测、FPS 或整城性能验收。

## 两座 Blender 外观精修地标（与漫游 / 普通楼 LOD 一起整合）

这次接入的是腾讯滨海双塔和中国华润大厦（春笋）。它们是可编辑的建筑级外观模型，不是 BIM、测绘或施工模型，
也不是把旧 JS 网格简单导出。原中心、朝向与总高保留，但窗格、柱截面、门窗和连廊层位仍含设计示意。

- **腾讯滨海**：245.8 / 194.8 米原双塔，新增折面/外挑遮阳面板、三条封闭玻璃连廊、外围门式框架、门厅台阶、屋面构件与独立灯带。
  **整个旧腾讯专用组已替换**，未叠加旧三层大裙楼/下沉庭院与旧桁架桥；最低连廊层位是示意，中上层按公开层位换算，非测绘标高。
- **华润春笋**：392.5 米原总高，新增 56→28 几何外柱、三角冠部玻璃/肋、底部门廊、楼层带和独立夜灯。
  塔形轮廓沿用原参数控制点作线性插值，不声称与旧曲线或实物逐点相同。
- 腾讯 28748、华润 36036 三角形，共 64784；按材质各合并为 7 个 mesh，白天隐藏夜灯后各 6 个可见。
  这些是资产几何计数，不是整场景 draw call/FPS（阴影还会增加 pass）。
- 两座都挂在 `buildingsGroup`，保留原地标 ID、卡片、标签、聚焦目标和通用楼跳过索引；可拾取 mesh 带原地标 ID。
- 日夜更新走独立 `setNight`，夜景关闭可立即清零；环境反射随三档画质/日暮环境变化，包含两种玻璃材质。
  新材质不会被旧全场材质修正逻辑覆盖。
- 新模型在漫游起点检查树内，但**不提供逐帧碰撞**；近距离仍可能穿过模型，可按 R 或返回总览。

内联数据是米制 Y-up，OBB 朝向已烘焙。运行时仅映射一次：`position=(rawX*.058,.09,rawZ*.058)`，
`scale=(.058,.112,.058)`，不得再旋转 OBB / 重复缩放。
`landmarks/inline-loader.js` 和两份 JSON 均由构建脚本嵌入 HTML，**没有 fetch / GLTFLoader / 在线纹理 / CDN 依赖**。
`.blend` / GLB 在源码包 `landmarks/assets/` 内，仅用于编辑，不是浏览器运行依赖；更改 `.blend` 不会自动修改现有内联 JSON。

本轮独立只读重开两份 `.blend`（Blender 5.0.1），核对 Blender / GLB / 内联的三角形数量及 GLB 无外部图像；
Node 中检查了实际安装函数、索引范围、位置/高度、地标射线、昼夜/反射策略和建筑父图层。**还没有浏览器/WebGL视觉或帧率验收。**
来源、真实变更和准确性边界见 `landmarks/README.md` 与交接档案 `landmarks/ASSET_NOTES.md`。

### 最后浏览器验收路线

1. **脱机**打开最终 HTML，确认总览启动，所有模型不依赖资源目录或网络。
2. 在地标下拉选腾讯滨海：看折面幕墙、封闭连廊、塔脚入口，确认没有旧大裙楼/桁架桥重叠；点击回原地标卡。
3. 选中国华润大厦：看底部外柱、门厅、收拢三角冠部；确认没有旧塔体叠影，标签聚焦与卡片正常。
4. 时间切至 23:00：两座窗光/连廊/冠部亮起；关夜景应熄灭。关建筑图层，两座整体应隐藏。
   切流畅/均衡/精美及白天/暮色，检查材质和环境反射无报错。
